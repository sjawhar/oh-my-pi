`history://<id>`: read-only condensed transcript; bare lists registered agents, not persisted unregistered top-level sessions. It keeps the user, assistant and developer text of the agent's current context; turns a compaction removed show only as a one-line summary, peer messages and other notices as one-line previews, job results as their labels, and each tool call as one line with its main argument and the result's status and line count (for an error, also its first line), not its output; thinking and most hidden messages are left out. `read` and `grep` see only this text, so a miss there does not mean something never happened. The session JSONL keeps every entry, tool results included: a root session's is `<timestamp>_<sessionId>.jsonl` (by default under `~/.omp/agent/sessions/`), and its subagents' are `<id>.jsonl` files under that path without the `.jsonl`.
